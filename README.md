# 🪷 Pancham Ved — Shrimad Bhagwat Mahapuran Gyanrahasya
### Landing Page · Udaipur, Rajasthan · 17–25 May 2025

A beautifully crafted, single-page event landing page for the **9-day Shrimad Bhagwat Mahapuran discourse** by **Pujaniya Raseshwari Devi Ji** in Udaipur, organized by **Braj Gopika Sadhana Mission (BGSM)**.

---

## 📋 About the Event

Pujaniya Raseshwari Devi Ji — a senior preacher in the tradition of **Jagadguru Swami Shri Kripalu Ji Maharaj** — will unveil the divine secrets (Gyanrahasya) of Shrimad Bhagwat Mahapuran over 9 consecutive days in the city of Udaipur, Rajasthan.

- **Dates:** 17th – 25th May 2025
- **Venue:** Udaipur, Rajasthan, India
- **Timings:** 6:30 PM – 8:30 PM daily
- **Entry:** Free for all

---

## 🌐 About This Project

This is a **pure HTML + CSS + Vanilla JS** single-file landing page. No frameworks, no build tools, no dependencies — just open `index.html` in any browser.

### Features

- ✅ Fully responsive (mobile + desktop)
- ✅ Animated hero with floating lotus petals and mandala
- ✅ Bilingual content (English + Devanagari Sanskrit shlokas)
- ✅ Interactive 9-day schedule with tabbed timeline
- ✅ Speaker profile — Pujaniya Raseshwari Devi Ji
- ✅ "Why Listen", "Benefits" and "What Makes This Unique" sections
- ✅ Photo gallery, video sneak-peek cards, and testimonials
- ✅ Venue map with transport info
- ✅ Registration form
- ✅ Sticky CTA bar + video modal
- ✅ Premium BGSM brand palette (deep indigo + gold)

## ✏️ Customization

To update event details, edit these sections inside `index.html`:

| What to Change | Where to Find It |
|---|---|
| Event dates / venue | Hero section → `.hero-date-strip` |
| Speaker photo | Speaker section → `<img class="speaker-real-img">` |
| YouTube video links | Videos section → `openModal()` calls |
| Registration form action | `#register` → `handleRegister()` in `<script>` |
| Venue name & map | `#venue` section |
| Contact details | Footer → `.footer-col` |
